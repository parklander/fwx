Problem notifications

A feed has to fail two checks in a row (about 20 min) before you're notified, and you get one notice when it recovers. These go only to devices added here, not to people who signed up for weather alerts. If the whole server is down nothing can be sent from it, so the DigitalOcean uptime check covers that by email.
